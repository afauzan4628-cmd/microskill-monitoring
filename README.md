# Sistem Monitoring Penyelesaian Microskill Peserta Digital Talent

## Deskripsi

Sistem berbasis web untuk memonitor penyelesaian Microskill peserta Digital Talent secara realtime. Sistem ini mengolah data pendaftar dan data respons menjadi dashboard monitoring dan laporan yang dapat diakses secara online.

## Fitur

- Dashboard Monitoring
- Monitoring Status Peserta
- Validasi / Crosscheck Data
- Rekap per Instansi
- Laporan Realtime
- Export PDF
- Pencarian & Filter Data
- Sinkronisasi Data

## Teknologi

- PHP Native
- MySQL
- HTML, CSS, JavaScript
- Bootstrap
- Dompdf
- PhpSpreadsheet
- Git & GitHub

## Instalasi

1. Clone repository

```bash
git clone https://github.com/afauzan4628-cmd/microskill-monitoring.git
```

2. Install dependency

```bash
composer install
```

3. Import database ke MySQL

4. Jalankan Apache dan MySQL melalui XAMPP

5. Buka browser

```
http://localhost/microskill-monitoring
```
